My Mathematical Modeling for Bioinformatics with R Portfolio
by Neshita Kipuw

Welcome! Below is a collection of my mathematical modeling reports and visualizations for Bioinformatics built using R.

Project Reports

  • Project 1: Understanding R Functions and Code
    Develop basic working experience with understanding and troubleshooting R code. Practice R features for accessing data, computing data summaries and creating data plots.
  • Project 2: Normal distribution & Hypothesis Testing
    Explore the notion of chance and how it applies to significance measures. Experiment with simulation studies using theoretical normal distribution. Understand the role of assumptions made by specific tests (i.e. t-test).
  • Project 3: Linear Models
    Explore linear models in R. Fitting linear model to a dataset, inspecting diagnostic plots and significance of model effects.
  • Project 4: Confidence Intervals
    Explore confidence intervals and their implementation in R. Each section includes a plot of the results, an interpretation of the results, a description of the code, and a description of how the code works.
