My Mathematical Modeling for Bioinformatics with R Portfolio
by Neshita Kipuw

Welcome! Below is a collection of my mathematical modeling reports and visualizations for Bioinformatics built using R.

Project Reports

  • Project 1: Understanding R Functions and Code
    Develop basic working experience with understanding and troubleshooting R code. Practice R features for accessing data, computing data summaries and creating data plots.
  • Project 2: Normal distribution & Hypothesis Testing
    Explore the notion of chance and how it applies to significance measures. Experiment with simulation studies using theoretical normal distribution. Understand the role of assumptions made by specific tests (i.e. t-test).
  • Project 3: Linear Models
    Explore linear models in R. Fitting linear model to a dataset, inspecting diagnostic plots and significance of model effects.
  • Project 4: Confidence Intervals
    Explore confidence intervals and their implementation in R. Each section includes a plot of the results, an interpretation of the results, a description of the code, and a description of how the code works.
  • Project 5: Genomics study analysis
    Apply data manipulation and analysis techniques to a dataset from a genomics study. Data obtained from the study of differences between mRNA and protein levels in humans and chimps by Fu, et al. available in PubMed Central. Specifically, two sets of data (with 143 and 159 genes/proteins in them respectively) presented as supplementary tables 3 and 4. The aim is to reproduce some of their results and perform some additional analyses.
  • Project 6: Resampling & multiple test correction techniques
    Practice resampling approaches and multiple test correction techniques by: 1) develop practical knowledge of using permutation for significance assessment and bootstrap for calculation of confidence intervals; 2) learn how to recognize and address issues presented by running large number of statistical tests.
  • Project 7: Cross-validations & linear regression models
    Develop practical experience performing cross-validation and bootstrap for predictive accuracy assessment and fitting and interpreting multiple linear regression models.
  • Project 8: Advanced regression models
    Practice fitting and interpreting advanced regression models in R.
  • Project 9: PCA & clustering
    Principal components analysis and hierarchical clustering in R.
  • Project 10: Various regression models to find significant genes
    Applying various regression models, perform comparison as to which provide better accuracy, apply it to a tumor dataset to find the most significant genes, and finally perform external validation with an outside dataset.
